# 📊 Учёт столовой "Вексель"

Программа для учёта выручки сотрудников в столовой, интегрированная с устаревшей DOS-системой. Разработана для расчётной группы предприятия.

## 📋 Описание

Приложение предназначено для автоматизации учёта наличных средств, полученных сотрудниками в столовой "Вексель". Программа позволяет:

- Фиксировать суммы, набранные каждым сотрудником
- Отслеживать собственную и готовую продукцию
- Формировать отчёты за день и месяц
- Экспортировать данные для дальнейшей обработки

## 🔌 Интеграция

Программа имеет прямой интерфейс с устаревшей DOS-системой учёта, что позволяет:
- Синхронизировать данные в реальном времени
- Избегать двойного ввода информации
- Сохранять историю операций

## 🛠️ Основной функционал

### 📈 Отчёты
- **По дням** — детализация за выбранную дату
- **По месяцам** — сводка за месяц
- **По сотрудникам** — фильтрация по табельному номеру

### 📊 Данные по сотрудникам
| Поле | Описание |
|------|----------|
| Табельный номер | Уникальный идентификатор сотрудника |
| ФИО | Полное имя сотрудника |
| Сумма | Общая сумма покупки |
| Собственная | Выручка с собственной продукции |
| Готовая | Выручка с готовой продукции |
| Код | Код операции |
| Дата/Время | Временная метка операции |
